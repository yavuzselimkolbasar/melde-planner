# ADR-0004: Windows-first development with macOS CI

## Decision
- Develop on Windows 11. Rust uses the GNU toolchain plus WinLibs MinGW, which avoids a multi-GB Visual Studio Build Tools install with admin rights.
- The Xcode project is generated by XcodeGen from `apps/ios/project.yml` and is not committed.
- GitHub Actions `macos-26` with Xcode 26.6 builds and tests the app; TestFlight uploads use cloud-managed signing with an App Store Connect API key.

## Consequences
- No local Simulator. UI review happens via TestFlight or a rented Mac.
- Windows CI uses the default MSVC toolchain while local development uses GNU. Both are tested, since `core.yml` runs on Windows.
